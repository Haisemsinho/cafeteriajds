## Como publicar depois da conferência

No JSON, para cada item confirmado: corrigir o que a JDS apontar e preencher `branchId` (`centro` ou `br116`), `stockStatus` e `published: true`. O importador só marca como oficial (`verified`) o item que tiver `published: true` **e** unidade definida. Depois definir `MENU_SOURCE=oficial` na Vercel.

## Como ver o cardápio em conferência

```bash
MENU_SOURCE=oficial SHOW_DRAFT_CONTENT=true npm run build
MENU_SOURCE=oficial SHOW_DRAFT_CONTENT=true npm run start
```

Sem `MENU_SOURCE=oficial`, o site continua com o cardápio de exemplo (`src/content/menu.ts`, mantido como backup). Em produção, sem `SHOW_DRAFT_CONTENT=true`, itens em conferência nunca aparecem.
